# Global instructions

## Answer format

Write all answers to me in ASD-STE100 Simplified Technical English. The full rules are in the "ASD-STE100" output style (`~/.claude/output-styles/ste.md`). Use this format only.

## Profile

Rules of the active profile (company or personal) are in `~/.claude/profile.md`. `install.sh --profile <name or path>` writes it. Without a profile the file does not exist.
